Schnellstart

Tutor1on1 nach Rolle verwenden.

Lehrer veröffentlichen und verwalten Kurse. Schüler beantragen die Einschreibung, laden freigegebene Inhalte herunter und erhalten Anleitung, Übungen und Fehlerwiederholung passend zu ihrem Fortschritt.

Zuerst installieren Lehrerablauf Schülerablauf Kursordner API config ChatGPT OAuth

Lehrerablauf

Kurse veröffentlichen und personalisieren.

  1. Als Lehrer anmelden oder ein Lehrerkonto registrieren.
  2. Eine lokale Kursversion erstellen oder laden.
  3. Das validierte Bundle in den Marketplace hochladen.
  4. Einschreibungsanfragen von Schülern genehmigen.
  5. Auf der Lehrer-Startseite Fortschritt, wiederkehrende Fehler und synchronisierte Sitzungen je Schüler prüfen.

Schülerablauf

Einschreiben und im eigenen Tempo lernen.

  1. Als Schüler anmelden oder ein Schülerkonto registrieren.
  2. Den Marketplace öffnen und Einschreibung in einen Kurs beantragen.
  3. Auf die Genehmigung durch den Lehrer warten.
  4. Das genehmigte Kurs-Bundle herunterladen.
  5. Den Kurs öffnen und eine Learn- oder Review-Sitzung starten, die dem eigenen Fortschritt folgt.

Kurse mit AI erstellen

PDF, PPT oder Unterrichtsnotizen in einen Tutor1on1-Kursordner umwandeln.

Nutzen Sie einen AI-Agenten außerhalb der App, um vorhandene Materialien neu zu formatieren. Tutor1on1 validiert, lädt, veröffentlicht und erlaubt danach gezielte Bearbeitung einzelner KP.

  1. Legen Sie PDF, PPT, Word-Dateien, Arbeitsblätter und Antwortnotizen in einen Quellordner. Bei Scans zuerst OCR ausführen und Formeln manuell prüfen.
  2. Lassen Sie Codex zuerst nur den contents.txt-Entwurf vorschlagen. Prüfen Sie Reihenfolge, Titel und Granularität der KP, bevor Dateien geschrieben werden.
  3. Lassen Sie Codex den Ausgabeordner erstellen. Jede id in contents.txt benötigt eine passende Datei <id>_lecture.txt. Optionale Fragenbanken heißen <id>_easy.txt, <id>_medium.txt und <id>_hard.txt.
  4. Laden Sie den Ordner als Lehrer in Tutor1on1. Wenn ein fehlender Dateiname oder eine ungültige id gemeldet wird, fügen Sie den Fehler in Codex ein und lassen den Ordner reparieren.
  5. Nach erfolgreichem Laden nutzen Sie per Rechtsklick AI edit content auf einem KP für kleinere Lektionen- oder Fragenbank-Änderungen.

Codex Web

  1. Erstellen Sie eine Aufgabe: Generate Tutor1on1 course folder from teaching materials.
  2. Laden Sie PDF/PPT/Word-Dateien hoch.
  3. Prompt: Read the uploaded materials and propose a Tutor1on1 contents.txt outline. Use dotted ids like 1, 1.1, 1.2. Do not generate files yet. Wait for my approval.
  4. Nach Freigabe des Entwurfs: Create a complete Tutor1on1 course folder with contents.txt, one <id>_lecture.txt for every id, and optional easy/medium/hard question files. Run a self-check and list missing files.
  5. Laden Sie den erzeugten Ordner oder die ZIP herunter, entpacken Sie sie und laden Sie den Ordner in Tutor1on1.

Codex Desktop oder lokale GUI

  1. Erstellen Sie source_materials/ für Originaldokumente und einen leeren Ausgabeordner wie special_relativity_course/.
  2. Öffnen Sie den übergeordneten Workspace in Codex.
  3. Prompt: Use source_materials/ as input. Create a complete Tutor1on1 course folder in special_relativity_course/. Do not modify source_materials/. First generate contents.txt, then generate all lecture and question files. After writing files, check that every contents.txt id has <id>_lecture.txt.
  4. Lassen Sie Codex direkt Dateien schreiben. Fordern Sie einen abschließenden self-check report an und laden Sie danach den Ausgabeordner in Tutor1on1.

AI edit course in Tutor1on1

  1. Nach dem Laden des Ordners öffnen Sie als Lehrer den Kurs-Skill-Tree.
  2. Klicken Sie mit der rechten Maustaste auf den Ziel-KP oder seinen Titel und wählen Sie AI edit content.
  3. Wählen Sie Content für Lektionstext oder Question für Fragenbank-Text zu diesem KP.
  4. Chatten Sie mit der AI, bis die letzte Antwort speicherbereit ist. Jede Anfrage sollte auf diesen KP fokussiert bleiben.
  5. Klicken Sie bei der AI-Antwort auf Edit, um das Diff-Fenster zu öffnen. Links steht der aktuelle Text, rechts können Sie den Vorschlag bearbeiten.
  6. Wählen Sie Add zum Anhängen oder Replace zum Überschreiben. Bei Fragen wählen Sie zusätzlich easy, medium oder hard.
  7. Speichern Sie die Änderung. Laden Sie das course bundle erneut hoch, wenn Marketplace-Schüler den aktualisierten Inhalt erhalten sollen.

Personalisierter Lernkreislauf

1

Lernen

Der Tutor erklärt das nächste Konzept im Kontext des Kurses und des aktuellen Fortschritts des Schülers.

2

Üben

Übungen passen sich den Antworten des Schülers an, mit Hinweisen, einfacheren Beispielen und positivem Feedback bei Bedarf.

3

Fehler wiederholen

Bedeutende Fehler werden im Fehlerheft zusammengefasst, damit spätere Wiederholung echte Schwächen trifft.

API config Felder

  • Provider wählt den Modelldienst, zum Beispiel OpenAI oder SiliconFlow.
  • Base URL ist der Endpoint, den Tutor1on1 für den gewählten Provider nutzt.
  • API Key wird lokal gespeichert und für Tutor, TTS und STT genutzt, wenn diese Funktionen ihn benötigen.
  • Test API key ruft {baseUrl}/models auf, prüft den key und lädt die verfügbaren Text-, TTS- und STT-Modelllisten. Es lädt keine Modelle herunter und wählt kein neues Modell automatisch aus.
  • Text model steuert die Tutor-Unterhaltung. Thinking effort erscheint nur bei Providern, die Reasoning-Kontrollen unterstützen.
  • TTS model steuert Sprachausgabe. STT model steuert Sprache-zu-Text. Beide können leer bleiben, wenn Sprache nicht genutzt wird.
  • Saved API configs speichern Provider URL, gewählte Modelle, thinking effort und key hash, damit geprüfte Setups wiederverwendet werden können.

ChatGPT OAuth statt API key verwenden

  1. Öffnen Sie Settings, API Settings, und wählen Sie OpenAI Codex (ChatGPT OAuth) als Provider.
  2. Klicken Sie auf Login with ChatGPT und schließen Sie die Anmeldung im Browser ab. Wenn die App nicht automatisch zurückkehrt, fügen Sie den finalen redirect URL oder authorization code in den Dialog ein.
  3. Klicken Sie auf Refresh models, wählen Sie ein text model wie gpt-5.5 und speichern Sie die API config.
  4. Starten oder öffnen Sie eine tutor-Sitzung erneut und wählen Sie im Modellwähler das gespeicherte Codex OAuth Modell.

Diese Option nutzt ChatGPT/Codex OAuth quota für Tutor-Textgespräche. TTS und STT verwenden weiterhin API-key Provider, wenn Sprache benötigt wird.

Marketplace

Kurse entdecken

Lehrer veröffentlichen Kursangebote. Schüler stöbern, beantragen Einschreibung und laden nach Genehmigung herunter.

Sessions

Persönliches Feedback

Learn dient neuem Stoff und Review der Abrufübung. Feedback passt sich der Antwort des Schülers an und macht Fortschritt sichtbar.

Sync

Kontinuität

Lehrer- und Schüler-Startseiten synchronisieren kontoverknüpfte Einschreibungen, Sitzungen, Fortschritt und Fehlerheft-Signale.

Häufige Probleme

  • Wenn Anmeldung oder Kursladen fehlschlägt, prüfen Sie, ob die App api.tutor1on1.org erreicht.
  • Wenn ein Schüler nicht in einen Kurs kommt, prüfen Sie, ob die Einschreibung genehmigt und das Bundle heruntergeladen wurde.
  • Wenn Modelllisten veraltet wirken, führen Sie Test API key erneut für den aktiven Provider und key aus.
  • Wenn Fortschritt auf mehreren Geräten veraltet wirkt, warten Sie auf Sync oder starten Sie eine manuelle Aktualisierung.
