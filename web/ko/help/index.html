역할에 맞게 Tutor1on1 사용하기.

교사는 코스를 공개하고 관리합니다. 학생은 수강을 신청하고 승인된 콘텐츠를 다운로드한 뒤, 자신의 진도에 맞는 지도, 연습, 오답 복습을 받습니다.

먼저 설치 교사 흐름 학생 흐름 코스 folder API config ChatGPT OAuth

교사 흐름

코스를 공개하고 계속 개인화합니다.

  1. 교사로 로그인하거나 교사 계정을 등록합니다.
  2. 로컬 코스 버전을 만들거나 불러옵니다.
  3. 검증된 bundle을 marketplace에 업로드합니다.
  4. 학생 수강 신청을 승인합니다.
  5. 교사 홈에서 학생별 진도, 반복 오답, 동기화된 세션을 확인합니다.

학생 흐름

수강하고 자신의 속도로 공부합니다.

  1. 학생으로 로그인하거나 학생 계정을 등록합니다.
  2. marketplace를 열고 코스 수강을 신청합니다.
  3. 교사 승인을 기다립니다.
  4. 승인된 코스 bundle을 다운로드합니다.
  5. 코스를 열고 진도에 맞는 Learn 또는 Review 세션을 시작합니다.

AI로 코스 만들기

PDF, PPT, 수업 자료를 Tutor1on1 코스 folder로 변환합니다.

기존 자료는 먼저 외부 AI agent로 Tutor1on1용 folder로 정리합니다. Tutor1on1은 검증, 불러오기, 게시, 그리고 KP별 편집을 담당합니다.

  1. PDF, PPT, Word, 워크시트, 답안 메모를 source folder에 넣습니다. 스캔 자료는 먼저 OCR을 하고 수식과 도표를 직접 확인합니다.
  2. 처음에는 Codex에 contents.txt outline만 만들게 합니다. KP 순서, title, 단위를 확인한 뒤 파일 생성을 요청합니다.
  3. Codex에 출력 course folder를 만들게 합니다. contents.txt의 모든 id에는 대응하는 <id>_lecture.txt가 필요합니다. 선택 질문 파일은 <id>_easy.txt, <id>_medium.txt, <id>_hard.txt입니다.
  4. 교사로 Tutor1on1에서 folder를 불러옵니다. missing file 또는 id 오류가 나오면 그 오류를 Codex에 붙여 넣고 folder를 수정하게 합니다.
  5. 불러오기에 성공하면 KP를 오른쪽 클릭하고 AI edit content로 lesson 또는 질문 풀을 작게 수정합니다.

Codex web

  1. 새 작업을 만듭니다: Generate Tutor1on1 course folder from teaching materials.
  2. PDF/PPT/Word 파일을 업로드합니다.
  3. Prompt: Read the uploaded materials and propose a Tutor1on1 contents.txt outline. Use dotted ids like 1, 1.1, 1.2. Do not generate files yet. Wait for my approval.
  4. outline 승인 후 prompt: Create a complete Tutor1on1 course folder with contents.txt, one <id>_lecture.txt for every id, and optional easy/medium/hard question files. Run a self-check and list missing files.
  5. 생성된 folder 또는 zip을 다운로드하고 압축을 푼 뒤 Tutor1on1에서 불러옵니다.

Codex desktop 또는 local GUI

  1. 원본 문서용 source_materials/와 빈 출력 folder인 special_relativity_course/를 만듭니다.
  2. 그 상위 workspace를 Codex에서 엽니다.
  3. Prompt: Use source_materials/ as input. Create a complete Tutor1on1 course folder in special_relativity_course/. Do not modify source_materials/. First generate contents.txt, then generate all lecture and question files. After writing files, check that every contents.txt id has <id>_lecture.txt.
  4. Codex가 파일을 직접 쓰게 합니다. 마지막에 self-check report를 요청한 뒤 출력 folder를 Tutor1on1에서 불러옵니다.

개인 맞춤 학습 흐름

1

학습

Tutor는 코스 내용과 학생의 현재 진도를 바탕으로 다음 개념을 설명합니다.

2

연습

연습은 학생 답변에 맞춰 조정되며 필요할 때 힌트, 더 쉬운 예, 긍정적 피드백을 제공합니다.

3

오답 복습

의미 있는 오답은 오답 노트에 요약되어 이후 복습이 실제 약점을 겨냥하게 합니다.

API config 항목

  • Provider는 OpenAI 또는 SiliconFlow 같은 모델 서비스를 선택합니다.
  • Base URL은 Tutor1on1이 모델 서비스에 요청을 보내는 endpoint이며, 선택한 provider에 맞게 표시됩니다.
  • API Key는 로컬에 저장되며 tutor, TTS, STT 등 모델 서비스가 필요한 기능에 사용됩니다.
  • Test API key는 {baseUrl}/models를 호출해 key를 검증하고 사용 가능한 text, TTS, STT 모델 목록을 불러옵니다. 모델을 다운로드하지 않으며 새 모델을 자동 선택하지 않습니다.
  • Text model은 tutor 대화에 사용됩니다. Thinking effort는 reasoning control을 지원하는 provider에서만 표시됩니다.
  • TTS model은 음성 출력, STT model은 음성 입력 전사를 제어합니다. 음성을 쓰지 않으면 비워 둘 수 있습니다.
  • 저장된 API config는 provider URL, 선택한 모델, thinking effort, key hash를 저장해 검증된 설정을 다시 사용할 수 있게 합니다.

API key 대신 ChatGPT OAuth 사용

  1. Settings의 API Settings를 열고 Provider를 OpenAI Codex (ChatGPT OAuth)로 선택합니다.
  2. Login with ChatGPT를 누르고 브라우저에서 로그인을 완료합니다. 앱으로 자동 복귀하지 않으면 마지막 redirect URL 또는 authorization code를 대화상자에 붙여 넣습니다.
  3. Refresh models를 누르고 gpt-5.5 같은 text model을 선택한 뒤 API config를 저장합니다.
  4. tutor 세션을 시작하거나 다시 열고 모델 선택기에서 저장된 Codex OAuth 모델을 선택합니다.

이 옵션은 tutor 텍스트 대화에 ChatGPT/Codex OAuth quota를 사용합니다. 음성이 필요하면 TTS와 STT는 계속 API-key provider를 사용합니다.

Marketplace

Learn은 새 내용, Review는 회상 연습에 사용합니다. 피드백은 학생 답변에 맞춰 바뀌며 진도를 보이게 합니다.

Sync

연속성

교사와 학생 홈은 계정에 연결된 수강 상태, 세션, 진도, 오답 노트 신호를 동기화합니다.

자주 겪는 문제

  • 로그인이나 코스 로딩이 실패하면 앱이 api.tutor1on1.org에 연결되는지 확인하세요.
  • 학생이 코스에 들어갈 수 없으면 수강 신청이 승인되었고 bundle이 다운로드되었는지 확인하세요.
  • 모델 목록이 오래되어 보이면 현재 provider와 key로 Test API key를 다시 실행하세요.
  • 여러 기기의 진도가 오래되어 보이면 동기화 완료를 기다리거나 수동 새로고침을 실행하세요.
