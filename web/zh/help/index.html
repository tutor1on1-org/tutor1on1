快速开始

按角色使用 Tutor1on1。

老师发布并管理课程；学生申请报名、下载已批准内容，并获得符合个人进度的指导、练习和错题复习。

先安装 老师流程 学生流程 课程 folder API config ChatGPT OAuth

老师流程

发布并个性化管理课程。

  1. 以老师身份登录，或注册老师账号。
  2. 创建或加载本地课程版本。
  3. 将已校验的 bundle 上传到 marketplace。
  4. 审批学生报名请求。
  5. 在老师主页查看每个学生的进度、常见错误和同步过来的会话。

学生流程

报名并按自己的节奏学习。

  1. 以学生身份登录，或注册学生账号。
  2. 打开 marketplace，申请报名课程。
  3. 等待老师批准。
  4. 下载已批准的课程 bundle。
  5. 打开课程，开始跟随个人进度的 Learn 或 Review 会话。

用 AI 制作课程

把 PDF、PPT 或教学讲义转换成 Tutor1on1 课程 folder。

已有教学资料时，建议先用外部 AI agent 重新整理成课程 folder；Tutor1on1 负责校验、加载、上传，并支持后续对单个 KP 做 AI edit。

  1. 把 PDF、PPT、Word、讲义、题目和答案说明放进一个 source folder。扫描版先 OCR，公式和图表要人工检查。
  2. 先让 Codex 只生成 contents.txt 大纲。老师确认 KP 顺序、title 和粒度之后，再让它写文件。
  3. 让 Codex 生成输出课程 folder。contents.txt 里的每个 id 都必须有对应的 <id>_lecture.txt。题库可选，文件名为 <id>_easy.txt、<id>_medium.txt、<id>_hard.txt。
  4. 老师端加载输出 folder。如果 app 报 missing file 或 id 错误，把错误贴回 Codex，让它修复 folder。
  5. 课程加载成功后，对单个 KP 右键 AI edit content，继续微调 lesson 或题库。

Codex 网页版

  1. 新建任务：Generate Tutor1on1 course folder from teaching materials。
  2. 上传 PDF/PPT/Word 文件。
  3. 先提示 Codex：Read the uploaded materials and propose a Tutor1on1 contents.txt outline. Use dotted ids like 1, 1.1, 1.2. Do not generate files yet. Wait for my approval.
  4. 确认大纲后再提示：Create a complete Tutor1on1 course folder with contents.txt, one <id>_lecture.txt for every id, and optional easy/medium/hard question files. Run a self-check and list missing files.
  5. 下载生成的 folder 或 zip，解压后在 Tutor1on1 里加载这个 folder。

Codex 电脑 GUI / 本地版

  1. 创建 source_materials/ 放原始文档，再创建一个空输出 folder，例如 special_relativity_course/。
  2. 在 Codex 里打开这两个 folder 的上一级 workspace。
  3. 提示 Codex：Use source_materials/ as input. Create a complete Tutor1on1 course folder in special_relativity_course/. Do not modify source_materials/. First generate contents.txt, then generate all lecture and question files. After writing files, check that every contents.txt id has <id>_lecture.txt.
  4. 让 Codex 直接写文件，不要只在聊天里贴文本。最后让它输出 self-check report，然后在 Tutor1on1 里加载输出 folder。

在 Tutor1on1 里 AI edit course

  1. 课程 folder 加载成功后，老师打开 course skill tree。
  2. 在目标 KP node 或下方 title 上右键，选择 AI edit content。
  3. 选择 Content 生成 lesson 内容；选择 Question 生成当前 KP 的题库文本。
  4. 和 AI 对话，直到最新回复适合入库。每次请求都尽量围绕当前 KP。
  5. 点击 AI 回复上的 Edit 打开 diff 窗口。左侧是当前内容，右侧是 AI 建议内容，右侧可以手动改。
  6. 选择 Add 追加，或 Replace 覆盖。如果是 question，还要选择 easy、medium 或 hard。
  7. 保存后修改进入本地课程。需要让 marketplace 学生拿到新内容时，再重新上传 course bundle。

个性化学习闭环

1

学习

Tutor 会结合课程内容和学生当前进度，讲解下一步知识点。

2

练习

练习会根据学生回答调整，必要时给提示、更简单的例子和正反馈。

3

复习错题

有意义的错误会进入错题集，让后续复习真正针对薄弱点。

API config 里面的内容

  • 提供方选择模型服务，例如 OpenAI 或 SiliconFlow。
  • Base URL 是 Tutor1on1 请求模型服务的地址，应用会按当前提供方显示。
  • API Key 保存在本机，用于 tutor、TTS、STT 等需要模型服务的功能。
  • 测试 API key 会请求 {baseUrl}/models，验证 key，并加载可用的文本、TTS、STT 模型列表。它不会下载模型，也不会自动选择新模型。
  • 文本模型 用于对话式 tutor。Thinking effort 只在提供方支持 reasoning 控制时显示。
  • TTS 模型 控制语音输出；STT 模型 控制语音转文字。如果不用语音，可以留空。
  • 已保存的 API 配置 保存 provider URL、选择的模型、thinking effort 和 key hash，方便复用已验证配置。

不用 API key，改用 ChatGPT OAuth

  1. 打开设置里的 API Settings，把 Provider 选成 OpenAI Codex (ChatGPT OAuth)。
  2. 点击 Login with ChatGPT，在浏览器完成登录。如果应用没有自动返回，把最后的 redirect URL 或 authorization code 粘贴到弹窗里。
  3. 点击 Refresh models，选择文本模型，例如 gpt-5.5，然后保存 API 配置。
  4. 开始或重新打开 tutor 会话，在模型选择器里选择已保存的 Codex OAuth 模型。

这个选项使用 ChatGPT/Codex OAuth quota 来跑 tutor 文本对话。需要语音时，TTS 和 STT 仍然使用 API-key provider。

Marketplace

课程发现

老师发布课程展示；学生浏览课程、申请报名，并在批准后下载。

Sessions

个人反馈

Learn 用于新内容，Review 用于回忆练习。反馈会根据学生回答调整，并保持进步可见。

Sync

连续学习

老师和学生主页会同步已连接账号的报名、会话、进度和错题信号。

常见问题

  • 如果登录或课程加载失败，先确认应用能连到 api.tutor1on1.org。
  • 如果学生无法进入课程，先确认报名已批准，并且 bundle 已下载。
  • 如果模型列表看起来过期，对当前 provider 和 key 重新运行“测试 API key”。
  • 如果多设备进度不同步，等待同步完成，或手动刷新一次。
