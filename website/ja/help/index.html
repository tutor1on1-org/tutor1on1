役割ごとに Tutor1on1 を使う。

先生はコースを公開して管理します。生徒は受講申請を行い、承認済みコンテンツをダウンロードし、進度に合った指導、練習、ミス復習を受けます。

先にインストール 先生の流れ 生徒の流れ コース ZIP API config

先生の流れ

コースを公開し、継続的に個別化します。

  1. 先生としてログイン、または先生アカウントを登録します。
  2. コース ZIP をインポートします。
  3. 検証済み bundle を marketplace にアップロードします。
  4. 生徒の受講申請を承認します。
  5. 先生ホームで各生徒の進度、よくあるミス、同期済みセッションを確認します。

生徒の流れ

受講し、自分のペースで学びます。

  1. 生徒としてログイン、または生徒アカウントを登録します。
  2. marketplace を開き、コースの受講を申請します。
  3. 先生の承認を待ちます。
  4. 承認済みコース bundle をダウンロードします。
  5. コースを開き、進度に沿った Learn または Review セッションを始めます。

AI でコースを作る

PDF、PPT、授業ノートを Tutor1on1 のコース ZIP に変換します。

既存教材は、まず外部の AI agent で Tutor1on1 用に整え、ZIP にまとめます。Tutor1on1 は検証、インポート、公開、そして KP ごとの微調整を担当します。

  1. PDF、PPT、Word、ワークシート、解答メモを source folder に入れます。スキャン資料は先に OCR し、数式と図表を手で確認します。
  2. 最初は Codex に contents.txt の outline だけを作らせます。KP の順序、title、粒度を確認してからファイル生成へ進みます。
  3. Codex にコースファイルを作成させ、contents.txt が ZIP ルートにある ZIP にまとめます。contents.txt の各 id には必ず対応する <id>_lecture.txt が必要です。任意の問題プールは <id>_easy.txt、<id>_medium.txt、<id>_hard.txt です。
  4. Tutor1on1 で先生として Import course ZIP を選び、生成された ZIP を展開せずに直接選択します。missing file や id エラーが出たら、そのエラーを Codex に貼り、ZIP を修正して再作成させます。
  5. コース ZIP のインポート後は、KP を右クリックして AI edit content を使い、lesson や問題プールを小さく調整します。

Codex web

  1. 新しい task を作ります: Generate Tutor1on1 course ZIP from teaching materials.
  2. PDF/PPT/Word ファイルをアップロードします。
  3. Prompt: Read the uploaded materials and propose a Tutor1on1 contents.txt outline. Use dotted ids like 1, 1.1, 1.2. Do not generate files yet. Wait for my approval.
  4. outline を承認した後の prompt: Create a complete Tutor1on1 course ZIP with contents.txt at the ZIP root, one <id>_lecture.txt for every id, and optional easy/medium/hard question files. Run a self-check and list missing files.
  5. 生成された ZIP をダウンロードし、Tutor1on1 の Import course ZIP で展開せずに直接選択します。

Codex desktop または local GUI

  1. 原本用に source_materials/、出力用に空の special_relativity_course/ を作ります。
  2. その親 workspace を Codex で開きます。
  3. Prompt: Use source_materials/ as input. Create a complete Tutor1on1 course folder in special_relativity_course/. Do not modify source_materials/. First generate contents.txt, then generate all lecture and question files. Check that every contents.txt id has <id>_lecture.txt, then package the contents of special_relativity_course/ as special_relativity_course.zip with contents.txt at the ZIP root.
  4. Codex にファイルと ZIP を直接書かせ、最後に self-check report を出させます。Tutor1on1 の Import course ZIP で special_relativity_course.zip を展開せずに選択します。

Tutor1on1 内の AI edit course

  1. ZIP をインポートした後、先生として course skill tree を開きます。
  2. 対象 KP node または下の title を右クリックし、AI edit content を選びます。
  3. lesson 本文を作る場合は Content、その KP の問題プールを作る場合は Question を選びます。
  4. 最新の AI 返信が保存できる状態になるまで対話します。各依頼は現在の KP に集中させます。
  5. AI 返信の Edit を押して diff window を開きます。左が現在の内容、右が提案内容で、右側は手動編集できます。
  6. Add は追記、Replace は上書きです。Question の場合は easy、medium、hard も選びます。
  7. 保存します。Marketplace の生徒に更新を届けるには、course bundle を再アップロードします。

個別学習の流れ

1

学ぶ

Tutor はコース内容と生徒の現在の進度に合わせて、次の概念を説明します。

2

練習する

練習は生徒の回答に合わせて変わり、必要なときはヒント、より簡単な例、前向きなフィードバックを返します。

3

ミスを復習する

意味のあるミスはミスノートに要約され、後の復習が本当の弱点に向かいます。

API config の項目

  • Provider は OpenAI や SiliconFlow などのモデルサービスを選びます。
  • Base URL は Tutor1on1 がモデルサービスへ送信する endpoint です。選択中の provider に合わせて表示されます。
  • API Key はローカルに保存され、tutor、TTS、STT などモデルサービスが必要な機能で使われます。
  • Test API key は {baseUrl}/models を呼び出して key を検証し、利用可能な text、TTS、STT モデル一覧を読み込みます。モデルはダウンロードせず、新しいモデルを自動選択しません。
  • Text model は tutor 会話に使われます。Thinking effort は reasoning control をサポートする provider でのみ表示されます。
  • TTS model は音声出力、STT model は音声入力の文字起こしを制御します。音声を使わない場合は空欄で構いません。
  • 保存済み API config には provider URL、選択済みモデル、thinking effort、key hash が保存され、検証済み設定を再利用できます。
Marketplace

コースを見つける

先生はコース listing を公開します。生徒は閲覧、受講申請、承認後のダウンロードを行います。

Sessions

個別フィードバック

Learn は新しい内容、Review は想起練習に使います。フィードバックは生徒の回答に合わせて変わり、進歩を見える形にします。

Sync

継続性

先生と生徒のホームは、アカウントに紐づく受講状態、セッション、進度、ミスノート信号を同期します。

よくある問題

  • ログインまたはコース読み込みに失敗する場合は、アプリが api.tutor1on1.org に接続できるか確認します。
  • 生徒がコースに入れない場合は、受講申請が承認され、bundle がダウンロード済みか確認します。
  • モデル一覧が古く見える場合は、現在の provider と key で Test API key を再実行します。
  • 複数端末の進度が古い場合は、同期完了を待つか手動更新します。
