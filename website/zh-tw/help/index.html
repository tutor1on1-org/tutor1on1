快速開始

按角色使用 Tutor1on1。

老師發布並管理課程；學生申請報名、下載已批准內容，並獲得符合個人進度的指導、練習和錯題複習。

先安裝 老師流程 學生流程 課程 ZIP API config

老師流程

發布並個人化管理課程。

  1. 以老師身份登入，或註冊老師帳號。
  2. 匯入課程 ZIP。
  3. 將已校驗的 bundle 上傳到 marketplace。
  4. 審批學生報名請求。
  5. 在老師首頁查看每位學生的進度、常見錯誤和同步過來的會話。

學生流程

報名並按自己的節奏學習。

  1. 以學生身份登入，或註冊學生帳號。
  2. 打開 marketplace，申請報名課程。
  3. 等待老師批准。
  4. 下載已批准的課程 bundle。
  5. 打開課程，開始跟隨個人進度的 Learn 或 Review 會話。

用 AI 製作課程

把 PDF、PPT 或教學講義轉換成 Tutor1on1 課程 ZIP。

已有教學資料時，先用外部 AI agent 重新整理並打包成 ZIP；Tutor1on1 負責校驗、匯入、上傳，並支援後續對單個 KP 做 AI edit。

  1. 把 PDF、PPT、Word、講義、題目和答案說明放進一個 source folder。掃描版先 OCR，公式和圖表要人工檢查。
  2. 先讓 Codex 只生成 contents.txt 大綱。老師確認 KP 順序、title 和粒度之後，再讓它寫文件。
  3. 讓 Codex 生成課程文件並打包成 ZIP，contents.txt 必須位於 ZIP 根目錄。contents.txt 裡的每個 id 都必須有對應的 <id>_lecture.txt。題庫可選，文件名為 <id>_easy.txt、<id>_medium.txt、<id>_hard.txt。
  4. 老師在 Tutor1on1 裡選擇 Import course ZIP，直接選擇生成的 ZIP，不要解壓。如果 app 報 missing file 或 id 錯誤，把錯誤貼回 Codex，讓它修復並重新打包 ZIP。
  5. 課程 ZIP 匯入成功後，對單個 KP 右鍵 AI edit content，繼續微調 lesson 或題庫。

Codex 網頁版

  1. 新建任務：Generate Tutor1on1 course ZIP from teaching materials。
  2. 上傳 PDF/PPT/Word 文件。
  3. 先提示 Codex：Read the uploaded materials and propose a Tutor1on1 contents.txt outline. Use dotted ids like 1, 1.1, 1.2. Do not generate files yet. Wait for my approval.
  4. 確認大綱後再提示：Create a complete Tutor1on1 course ZIP with contents.txt at the ZIP root, one <id>_lecture.txt for every id, and optional easy/medium/hard question files. Run a self-check and list missing files.
  5. 下載生成的 ZIP，在 Tutor1on1 裡選擇 Import course ZIP 並直接選擇該文件，不要解壓。

Codex 電腦 GUI / 本機版

  1. 建立 source_materials/ 放原始文件，再建立一個空輸出 folder，例如 special_relativity_course/。
  2. 在 Codex 裡打開這兩個 folder 的上一級 workspace。
  3. 提示 Codex：Use source_materials/ as input. Create a complete Tutor1on1 course folder in special_relativity_course/. Do not modify source_materials/. First generate contents.txt, then generate all lecture and question files. Check that every contents.txt id has <id>_lecture.txt, then package the contents of special_relativity_course/ as special_relativity_course.zip with contents.txt at the ZIP root.
  4. 讓 Codex 直接寫文件並生成 ZIP，最後輸出 self-check report。然後在 Tutor1on1 裡選擇 Import course ZIP，直接選擇 special_relativity_course.zip，不要解壓。

在 Tutor1on1 裡 AI edit course

  1. 課程 ZIP 匯入成功後，老師打開 course skill tree。
  2. 在目標 KP node 或下方 title 上右鍵，選擇 AI edit content。
  3. 選擇 Content 生成 lesson 內容；選擇 Question 生成目前 KP 的題庫文字。
  4. 和 AI 對話，直到最新回覆適合入庫。每次請求都盡量圍繞目前 KP。
  5. 點擊 AI 回覆上的 Edit 打開 diff 視窗。左側是目前內容，右側是 AI 建議內容，右側可以手動改。
  6. 選擇 Add 追加，或 Replace 覆蓋。如果是 question，還要選擇 easy、medium 或 hard。
  7. 保存後修改進入本機課程。需要讓 marketplace 學生拿到新內容時，再重新上傳 course bundle。

個人化學習閉環

1

學習

Tutor 會結合課程內容和學生目前進度，講解下一步知識點。

2

練習

練習會根據學生回答調整，必要時給提示、更簡單的例子和正向回饋。

3

複習錯題

有意義的錯誤會進入錯題集，讓後續複習真正針對薄弱點。

API config 內的內容

  • Provider 選擇模型服務，例如 OpenAI 或 SiliconFlow。
  • Base URL 是 Tutor1on1 請求模型服務的地址，應用會按目前提供方顯示。
  • API Key 保存在本機，用於 tutor、TTS、STT 等需要模型服務的功能。
  • Test API key 會請求 {baseUrl}/models，驗證 key，並載入可用的文字、TTS、STT 模型列表。它不會下載模型，也不會自動選擇新模型。
  • Text model 用於對話式 tutor。Thinking effort 只在提供方支援 reasoning 控制時顯示。
  • TTS model 控制語音輸出；STT model 控制語音轉文字。如果不用語音，可以留空。
  • 已儲存的 API config 保存 provider URL、選擇的模型、thinking effort 和 key hash，方便重用已驗證配置。
Marketplace

課程發現

老師發布課程展示；學生瀏覽課程、申請報名，並在批准後下載。

Sessions

個人回饋

Learn 用於新內容，Review 用於回憶練習。回饋會根據學生回答調整，並保持進步可見。

Sync

連續學習

老師和學生首頁會同步已連接帳號的報名、會話、進度和錯題信號。

常見問題

  • 如果登入或課程載入失敗，先確認應用能連到 api.tutor1on1.org。
  • 如果學生無法進入課程，先確認報名已批准，並且 bundle 已下載。
  • 如果模型列表看起來過期，對目前 provider 和 key 重新執行「Test API key」。
  • 如果多裝置進度不同步，等待同步完成，或手動刷新一次。
